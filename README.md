# Programming in Python (Course: M4010104 / M4020104)

Interactive lecture workbooks, laboratory practical sheets, classroom assessments, and capstone engineering specifications for undergraduate computer science and data engineering students.

## Course Modules & Notebooks

| Week | Module | Primary Topics | Core Notebooks |
| :--- | :--- | :--- | :--- |
| **Week 06** | Module 2 | Functional programming (`lambda`, `map`, `filter`, `reduce`), modules & custom packages | `Week6_Laboratory_Worksheet.ipynb` |
| **Week 07** | Module 2 | String & list methods, defensive File I/O (`try-except`), structured audit logging | `Week7_Python_Lecture_and_Lab_Workbook.ipynb`<br>`Week7_Laboratory_Worksheet.ipynb` |
| **Week 08** | Module 2 | Object-Oriented Programming (OOP): classes, constructors, encapsulation, inheritance | `Week8_Python_Lecture_and_Lab_Workbook.ipynb` |
| **Week 09** | Module 3 | Numerical computing with NumPy: arrays, vectorization, boolean masking, linear algebra | `Week9_Python_Lecture_and_Lab_Workbook.ipynb` |
| **Week 10** | Module 3 | Tabular data analysis with Pandas: `Series`, `DataFrame`, indexing, missing data imputation | `Week10_Python_Lecture_and_Lab_Workbook.ipynb` |
| **Week 11** | Module 3 | Advanced Pandas: joins/merges, multi-index aggregation (`groupby`), reshaping (`pivot`, `melt`) | `Week11_Python_Lecture_and_Lab_Workbook.ipynb` |

## Assessments & Capstone Projects

* **Classroom Tests & Mid-Semester Exams**: Timed practical problem sets with both student skeleton workbooks and instructor solution keys.
* **Capstone Project Specifications (Projects 01–21)**: 21 comprehensive engineering specifications covering climate analytics, Malayalam NLP, IoT sensor telemetry, renewable energy, and healthcare datasets using pure Python, NumPy, Pandas, Matplotlib, Seaborn, and Plotly.
