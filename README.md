# Programming in Python (Course: M4010104 / M4020104)

Interactive lecture workbooks, laboratory practical sheets, classroom assessments, and capstone engineering specifications for undergraduate computer science and data engineering students.

## Course Modules & Notebooks

Weekly worksheets along with teaching notes

## Assessments & Capstone Projects

* **Classroom Tests & Mid-Semester Exams**: Timed practical problem sets with both student skeleton workbooks and instructor solution keys.
* **Capstone Project Specifications (Projects 01–21)**: 21 comprehensive engineering specifications covering climate analytics, Malayalam NLP, IoT sensor telemetry, renewable energy, and healthcare datasets using pure Python, NumPy, Pandas, Matplotlib, Seaborn, and Plotly.
